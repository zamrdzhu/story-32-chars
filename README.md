A Wi-Fi network name that lands a joke and implies a whole story, written for make.fun's "Tell a Whole Story in 32 Characters" bounty.

## The name

> MyExTookTheRouter

## Run it

```sh
python3 main.py
```

The program prints exactly one network name and writes the same name (no trailing newline) to `/output/entry.txt`.

## Why this name

It works because a passer-by reading a phone's network list gets the entire breakup in four words. The joke is instant — of all the things an ex could take, they took the router, the one object that turns a home back into a dead zone — and the story writes itself around it: the argument, the packing, the petty final grab, and now the flatmate sitting in the dark refreshing a network that will never come back. It is fresh (a breakup told through household infrastructure), it is tight (17 characters, no spaces, no punctuation), and it is exactly the kind of name a real person would actually set after exactly this breakup. The router is the modern equivalent of taking the dog. One name, 17 characters, well inside the 32-character gate.
